# Export Formats

Technical reference for export outputs and options.

## Markdown

- Primary editable format
- Includes front matter sections per step
- Screenshot paths included when **Screenshots** toggle is on
- Paths stripped when toggle is off

## HTML

- Generated by `src-tauri/src/export/styled_html.rs`
- Supports dark/light themes and accent colors
- Optional cover page with session metadata
- Live preview in the Export studio matches output

## PDF

- Rendered from styled HTML via headless Chrome
- Page size: **Letter** (816px) or **A4** (794px)
- Requires Chrome/Chromium in PATH for best results

## Video

- Exports session screen recording when captured
- Platform-dependent capture method (see [Cross-Platform](../development/cross-platform))

## ExportOptions (API)

Frontend `ExportOptions` maps to the Rust export command:

```typescript
type ExportOptions = {
  theme: "dark" | "light";
  accent: "mint" | "blue" | "violet" | "amber";
  pageSize: "letter" | "a4";
  cover: boolean;
  screenshots: boolean;
  stepNumbers: boolean;
  timestamps: boolean;
  annotations: boolean;
  branding: boolean;
};
```

## White-label exports

Set **Branding** to off for exports without FlowCapture logo or footer text.
